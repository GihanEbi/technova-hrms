# Video Guide

Screen recordings of real browser sessions in the running application, captured automatically with Playwright (`npm run docs:videos`). Each video shows one workflow at 1440 × 900 with a visible cursor. WebM is the original Playwright recording; an MP4 copy is generated by `npm run docs:generate` when `ffmpeg` is available.

| # | Walkthrough | Role(s) | What it shows | Video |
| --- | --- | --- | --- | --- |
| 01 | Application overview | Admin | Sign in, explore the dashboard and date filter, use the sidebar, collapse/expand it, switch to dark and back to light, open notifications and the profile menu | [WebM](videos/01-application-overview.webm) · [MP4](videos/01-application-overview.mp4) |
| 02 | Employee management | HR Manager | Search and filter the directory, open a profile and its tabs, add a new employee, edit their details and save | [WebM](videos/02-employee-management.webm) · [MP4](videos/02-employee-management.mp4) |
| 03 | Attendance management | HR Manager | Attendance overview, clock in, clock out with hours worked, attendance history, submit a correction, corrections queue | [WebM](videos/03-attendance-management.webm) · [MP4](videos/03-attendance-management.mp4) |
| 04 | Leave management | Employee → Team Lead → Employee | Check balance, apply for leave with dates, submit, switch to the manager, approve, verify the updated status and notification | [WebM](videos/04-leave-management.webm) · [MP4](videos/04-leave-management.mp4) |
| 05 | Payroll management | Payroll Manager | Payroll dashboard, edit a salary structure, generate payroll, review warnings and a breakdown, submit, approve, process, open and download a payslip PDF | [WebM](videos/05-payroll-management.webm) · [MP4](videos/05-payroll-management.mp4) |

| 08 | Employee self-service | HR Manager → Employee | Switch to the employee role, dashboard, profile, clock in, apply for leave, open the latest payslip, ask the AI assistant | [WebM](videos/08-employee-self-service.webm) · [MP4](videos/08-employee-self-service.mp4) |

## Regenerating the videos

```bash
npm run build && npm run start   # in one terminal (or let Playwright start the server)
npm run docs:videos              # records all eight walkthroughs into docs/videos/
npm run docs:verify              # confirms every file exists and is non-empty
```

The recordings use a fresh browser context, freshly seeded demo data and a fixed demo clock (Fri 30 Oct 2026, 10:30 Asia/Colombo), so re-recording produces the same flows.
